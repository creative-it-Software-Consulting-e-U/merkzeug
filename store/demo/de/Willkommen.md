# Ein kleiner Platz für große Ideen

Gedanken festhalten. Verbindungen entdecken. Etwas daraus machen.

Merkzeug speichert deine Notizen als gewöhnliche **Markdown-Dateien**. Dieses erfundene Notizbuch zeigt, wie aus einzelnen Gedanken ein Ganzes wird.

## Diese Woche im Fokus

- [x] Erste Ideen sammeln
- [x] Einen einfachen Plan skizzieren
- [ ] Aus dem Plan einen hilfreichen Leitfaden machen

## Einer Idee folgen

Unser [Gemeinschaftsgarten](Projekte/Garten.md) beginnt mit einem kleinen Stück Erde und einem gemeinsamen Notizbuch. Der [Projektplan](Projekte/Plan.md) hält die nächsten Schritte fest.

> Gute Notizen lassen Platz für den nächsten Gedanken.

## Notizen, die dir gehören

Nutze Überschriften, Listen, Links und Tabellen. Behalte die Dateien in einem Ordner deiner Wahl und öffne sie bei Bedarf mit anderen Markdown-Werkzeugen.
