# Ein Schritt nach dem anderen

## Vorbereiten

- [x] Einen sonnigen Platz auswählen

## Alle sind willkommen

Bring ein Notizbuch, ein paar Samen und eine Idee mit. Erfahrung im Gärtnern ist nicht nötig.

| Mitbringen | Wofür |
| --- | --- |
| Samen | Etwas Neues beginnen |
| Schilder | Gepflanztes wiederfinden |
| Ein Notizbuch | Gelerntes festhalten |
