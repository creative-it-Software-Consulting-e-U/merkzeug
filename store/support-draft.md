# Merkzeug support — draft

Merkzeug is a visual editor for Markdown files. Start with the [user documentation](../docs/user/README.md), including [troubleshooting](../docs/user/troubleshooting.md).

To report a problem, include the Merkzeug version, operating system, edition and steps to reproduce it. Mention whether the folder is local or managed by a file provider. Attach only fictional examples and screenshots without personal or confidential information.

The owner selected the shared [App Support service](https://support.apps.creative-it.com/?app=merkzeug&lang=en), also used by GeoHook. The Merkzeug app registry entry must be deployed and verified before submission. The project's public issue tracker can be linked after the repository is public. Security reports should use the private contact described in [SECURITY.md](../SECURITY.md).

Publication task: host a reviewed version at a stable public URL and enter that URL in App Store Connect. Do not publish the word “draft” or unresolved publisher information in the final support page.
