# Willkommen bei MyNotion

Das ist dein **WYSIWYG-Markdown-Editor**. Alles, was du hier siehst, wird als *sauberes Markdown* gespeichert.

## Schnellstart

- Tippe `# ` am Zeilenanfang für eine Überschrift
- Tippe `- ` für eine Aufzählung, `1. ` für eine nummerierte Liste
- Tippe `> ` für ein Zitat, ` ``` ` und Enter für einen Codeblock
- **⌘B** fett, **⌘I** kursiv, **⌘E** `Inline-Code`, **⌘K** Link
- Bilder einfach per Drag & Drop oder Paste einfügen — sie landen automatisch im Ressourcen-Ordner der Notiz

## Tabellen

| Funktion | Shortcut |
| --- | --- |
| Tabelle einfügen | ⌥⌘T |
| Nächste Zelle | Tab |
| Neue Zeile am Ende | Tab in der letzten Zelle |

> Tipp: Rechtsklick in eine Tabelle zeigt alle Zeilen-/Spalten-Befehle.
