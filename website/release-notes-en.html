Release notes

Features, updates and release status for Merkzeug.

Mac · iPhone · iPad · IntelliJ

Merkzeug 1.2

Released

  • Choose a central PDF template or a template inside your vault from the PDF controls in every edition. Vault-relative template settings travel with your repository.
  • iPhone and iPad: export and print single notes or linked document collections with templates, cover pages, headers, footers and frontmatter settings.
  • Read the complete release history in the app. New versions show their release notes automatically on first launch.

macOS · iOS · iPadOS

Merkzeug 1.1

Released

  • Links between notes stay intact when you rename or move files in Merkzeug.
  • Meeting notes use their first heading as the filename and follow later heading changes.
  • Selected table text stays readable on light backgrounds and with PDF template styles.
  • The guided tour now explains reading mode and navigation between linked notes.
  • Mac: Your open vault windows and their positions are restored when Merkzeug starts again.
  • Mac: Print notes using your PDF templates and share templates with iPhone and iPad through iCloud.
  • Mac: Tour commands are now in the Help menu, leaving more room for your notes.
  • iPhone & iPad: Create meeting notes from your iPhone or iPad calendars; fixed a vault-path error when selecting an event.
  • iPhone & iPad: Use PDF template styles while editing, share templates through iCloud and print with AirPrint.
  • iPhone & iPad: Long-press file menus no longer accidentally select text; dismissing search is more reliable.

IntelliJ

Merkzeug 1.0.1

Released · 2026-09-22

  • Rename and Move update incoming Markdown links across project notes, including notes without image folders. Moving notes also recalculates outgoing relative links; native Undo/Redo is supported.
  • Print notes through File → Print or the editor toolbar using the PDF template.
  • Selected table text remains readable on light backgrounds and with PDF template styles.
  • Compatibility extended to IntelliJ IDEA 2026.2.3.

macOS · iOS · iPadOS

Merkzeug 1.0

Released · 2026-09-22

  • Explore and visually edit Markdown collections in your own folders and repositories.
  • Follow links, read Mermaid diagrams, and edit frontmatter.
  • On Mac: create meeting notes from calendar events, use Git, and export PDFs with reusable templates.
  • On iPhone and iPad: open folders through Files, including compatible providers such as Working Copy.
  • English and German interfaces, built-in guides and contact support.

IntelliJ

Merkzeug 1.0.0

Released · 2026-09-11

  • First IntelliJ Marketplace beta: a visual Markdown editor alongside other Markdown editors, with inline Mermaid editing and frontmatter.
  • PDF templates for editing and export, automatic discovery of desktop templates, and linked-document export.
  • Companion image folders follow IntelliJ Move/Rename refactorings. Optional instructions for AGENTS.md and CLAUDE.md help agents follow the same rules.
