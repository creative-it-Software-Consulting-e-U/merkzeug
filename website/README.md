# Merkzeug website

Static English/German landing page for `merkzeug.creative-it.com`, deployed with
the manually triggered GitHub Pages workflow. No analytics, remote fonts or app
download promises are included. Store links should only be added after approval.

Before the first deployment, review both privacy and legal pages with the
publisher, verify the production App Support endpoint accepts `app=merkzeug`,
enable Pages in repository settings and configure the custom-domain DNS/TLS.
The app repository can remain private if its GitHub plan supports public Pages.
Do not change repository visibility as a workaround.

Screenshots are development previews using fictional data. Update them if the
shipping interface changes. The site is independent of the application builds.
