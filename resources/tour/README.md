# Guided tour screencast

`guided-tour-de.mp4` is a silent German screencast of the actual desktop renderer using a synthetic local Git vault. It is bundled for local, on-demand playback across editions and clearly labeled as a desktop tour. No network request is made for playback.

Regenerate with `node scripts/capture-guided-tour.mjs` after building desktop. Review the result under `release-artifacts/roadmap/`, then copy the approved asset here. The script never uploads. YouTube publication remains a separate maintainer action under issue #49; no public video ID or URL is invented.
