## What is a vault?

A vault is an ordinary folder containing Markdown notes and their images. There is no database to import or proprietary document format to convert. Opening a folder grants Merkzeug access to its contents; it does not upload the folder to a Merkzeug service.

Git operations connect to the remote you configure. External links and remote images can contact their destination servers. A cloud file-provider folder may sync through its provider. The desktop calendar feature reads calendars configured on your computer.

## Language and editions

Primary project documentation is in English. The interface uses German on German systems and English otherwise. Desktop and iOS help follow the system language and also offer a language selector. Native system and IDE dialogs may follow the host's language. Note contents can use any language.

The editions share editing code but have different file and application features. Desktop provides a vault browser and Git commands. IntelliJ uses the IDE's project browser, saving and Git integration. iOS delegates Git operations to a separate app. PDF export is currently available on desktop and IntelliJ only.
